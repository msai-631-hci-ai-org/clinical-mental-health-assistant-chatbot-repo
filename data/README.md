# Knowledge-base data

Place reviewed `.pdf`, `.md`, or `.txt` files in this directory. The ingestion
command recursively discovers these formats and records the source filename and
PDF page number for retrieval transparency.

Only use material that:

- comes from a trusted source such as NIMH, CDC, NIH, SAMHSA, or WHO;
- the project is permitted to copy and process;
- has a recorded review date and source URL;
- has been reviewed for the intended audience and project scope.

`README*` files are intentionally excluded from ingestion. The included
`starter_knowledge_base.md` is a small, paraphrased demonstration corpus, not a
replacement for a clinically governed knowledge base.
